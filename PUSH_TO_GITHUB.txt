📌 LANGKAH 2: PUSH KE GITHUB

   Setelah repository dibuat, jalankan command ini:
   (Ganti USERNAME dengan username GitHub kamu)

   git remote add origin https://github.com/USERNAME/lab-untuk-ocr.git
   git push -u origin main

   CONTOH:
   git remote add origin https://github.com/johndoe/lab-untuk-ocr.git
   git push -u origin main

⚠️ CATATAN PENTING:

   1. Saat push, kamu akan diminta login GitHub

   3. Cara buat token:

      - Generate new token (classic)
      - Centang scope: repo
      - Copy token yang muncul
